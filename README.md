# ☁️ Microsoft Azure – Data Engineering Projects

Hands-on Azure data engineering projects built with **Azure Data Factory (ADF)**, documented step by step as PDF walkthroughs.

## 🛠️ Tech Stack
Azure Data Factory · Azure Data Lake Storage Gen2 · Azure SQL Database · Pipelines · Dataflows · Triggers

## 📂 Projects

| # | Project | What it covers |
|---|---------|----------------|
| 1 | **Microsoft Azure** (`MICROSOFT AZURE.pdf`) | Introduction and setup: resource group, storage account, ADF workspace, first pipeline |
| 2 | **Microsoft Azure (IF)** (`MICROSOFT AZURE(IF).pdf`) | Conditional logic using the If Condition activity |
| 3 | **Azure Data Flow** (`MICROSOFT AZURE DF.pdf`) | Data transformations with Mapping Data Flows |
| 4 | **Incremental Loading** (`INCRLOADING.pdf`) | Loading only new or changed records (watermark approach) |
| 5 | **Google Flights Pipeline** (`MICROSOFT AZURE GOOGLE FLIGHTS.pdf`) | Ingesting and processing flight data end to end |
| 6 | **Google News Pipeline** (`MICROSOFT AZURE GOOGLE NEWS.pdf`) | Ingesting and processing news data end to end |

## 🔄 General Workflow
Source → Ingest (ADF Copy Activity) → Transform (Data Flow) → Store (ADLS Gen2 / Azure SQL) → Monitor

## 📌 Key Learnings
- Building and parameterizing ADF pipelines
- Incremental vs. full loads
- Control flow (If Condition, ForEach, etc.)
- Monitoring and debugging pipeline runs
